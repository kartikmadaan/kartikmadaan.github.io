One-line notes on things I recommend often. Links are public and stable as of 2026.

## Books

- [*Designing Data-Intensive Applications*](https://dataintensive.net/) (Martin Kleppmann) — the map for distributed data systems.
- [*Database Internals*](https://www.databass.dev/) (Alex Petrov) — storage and query execution without hand-waving.
- [*Learning Go*](https://www.oreilly.com/library/view/learning-go-2nd/9781098139285/) (Jon Bodner, O'Reilly Media, 2nd ed., 2024) — idiomatic, real-world Go; updated for modern generics and Go tooling.
- [*Influence: The Psychology of Persuasion*](https://www.influenceatwork.com/books/influence/) (Robert Cialdini) — how persuasion works in the wild—useful even when you're not "in sales."

## Courses

- [CS50x — Introduction to Computer Science](https://cs50.harvard.edu/x/) (Harvard / David J. Malan) — algorithms, C, Python, SQL, and web basics in one rigorous arc; strong foundation if you're self-taught.

## Blogs

- [Julia Evans](https://jvns.ca/) — clear explanations with personality.
- [Brandur](https://brandur.org/) — thoughtful engineering essays.
- [The Go Blog](https://go.dev/blog/) — language and stdlib direction from the source.
- [Use The Index, Luke](https://use-the-index-luke.com/) — practical SQL indexing.

## Tools

- [Hugo](https://gohugo.io/) — fast static sites; extended build for assets.
- [ripgrep](https://github.com/BurntSushi/ripgrep) — search that respects `.gitignore`.
- [jq](https://jqlang.org/) — JSON plumbing in the shell.
- [Git](https://git-scm.com/) — still the baseline for collaboration.
- [Cursor](https://cursor.com/) — editor with agents; rules/skills make it usable at scale.

## Talks

- [Jay Kreps — The Log](https://www.youtube.com/watch?v=fdediuAKeuI) — why append-only logs underpin so many systems.
- [Martin Kleppmann — Turning the database inside out](https://www.youtube.com/watch?v=fU9hR3kiOK0) — streams, caches, and derived data.
